# Adarsha Naskar | Developer Portfolio

A modern, responsive developer portfolio showcasing my technical skills, featured projects, education, and contact information.

## 🔗 Live URL

https://dev-pf.netlify.app/

## 🚀 Overview

This portfolio is designed to present my journey as a Full Stack Web Developer, highlight the projects I've built, and provide an easy way to connect with me.

Built with a clean interface, modern styling, interactive components, and responsive layouts.

## ✨ Features

- **Modern UI:** Minimal and clean developer portfolio design.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Dark / Light Mode:** Switch between themes with saved preferences.
- **Interactive Navigation:** Smooth scrolling and responsive hamburger menu.
- **About Section:** Introduction and educational background.
- **Skills Showcase:** Overview of programming languages, frameworks, and tools.
- **Featured Projects:** Dedicated project cards with interactive detail popups.
- **Scroll Animations:** Smooth reveal effects while navigating sections.
- **Resume Access:** Option to view and download my resume.
- **Contact Section:** Direct email and social media links.

### 1. Clone the repository

```bash
git https://github.com/AdarshaNaskar/Datheon_Full_Stack_Web_Development_Internship.git
```

### 2. Navigate to the project directory

```bash
cd YOUR-REPOSITORY
```

### 3. Run the project

Open `index.html` in your browser or use the **Live Server** extension in VS Code.

No additional dependencies or build tools are required.
