# TaskFlow – Task Management & Productivity Tracker

TaskFlow is a simple and intuitive task management application designed to help users organize their daily activities, manage tasks, and track their productivity through a clean and user-friendly interface.

Link - https://task2-taskflow.netlify.app/
## 🚀 Features

- **Create Tasks:** Add new tasks with titles, categories, and due dates.
- **Update Tasks:** Edit existing task details.
- **Delete Tasks:** Remove tasks when they are no longer needed.
- **Task Categories:** Organize tasks into Work, Personal, and Study.
- **Task Completion:** Mark tasks as completed or active.
- **Task Filtering:** Filter tasks by All, Active, and Completed.
- **Local Storage:** Automatically saves tasks in the browser, keeping data available after refreshing the page.
- **Responsive Design:** Works across different screen sizes.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## ⚙️ Getting Started

1. Open the project folder.
2. Locate the `index.html` file.
3. Open it in your preferred web browser.
4. Start managing your tasks!

No additional dependencies or installations are required.

## 💡 How It Works

1. Add a task by entering its details.
2. Select a category and due date.
3. Edit or delete tasks whenever necessary.
4. Mark tasks as completed once finished.
5. Use filters to view all, active, or completed tasks.
6. Tasks are automatically saved using browser Local Storage.

## 🎯 Project Objective

The objective of TaskFlow is to build a practical productivity application while implementing fundamental JavaScript concepts, including DOM manipulation, event handling, CRUD operations, and browser Local Storage.
